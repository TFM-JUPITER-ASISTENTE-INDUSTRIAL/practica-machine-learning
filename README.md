## Instalación y configuración del entorno
- Creación del entorno virtual con *uv venv .venv --python 3.11*
- Activacion *source .venv/bin/activate*
- Instalar dependencias *uv pip install -r requirements.txt*
- Registro del kernel en Jupyter para desarrollo *python -m ipykernel install --user --name=practica-ml --
  display-name="Python (Práctica ML)"*
